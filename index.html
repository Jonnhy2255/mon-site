Comment jouer ▼
  1. Une bille rouge est placée sous l'un des trois gobelets.
  2. Les gobelets se soulèvent brièvement pour vous montrer où est la bille, puis redescendent.
  3. Les gobelets s'échangent rapidement de position. Suivez attentivement celui qui contient la bille.
  4. Après le mélange, les gobelets reprennent leurs positions d'origine (gauche, milieu, droite).
  5. Cliquez sur le gobelet où vous pensez que se trouve la bille.
  6. Si vous avez raison, vous marquez des points et passez au niveau suivant.
